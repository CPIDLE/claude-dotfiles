# 版型：左右對比型（Comparison）——「導入前 vs 導入後：AI 審核流程」

適用主題：Before/After、方案 A vs 方案 B、兩種選項的優劣對照。核心特徵是「一條中軸分隔線＋左右對稱的兩欄」，讓讀者一眼比較差異。

套用到新專案時，複製這份的**結構**（標題區／左右兩欄／中軸分隔／底部差異列），內容全部換成自己的主題。

---

生成一張寬版(16:9)扁平化商業資訊圖表，純白背景 #FFFFFF，繁體中文，風格盡量貼近 ChatGPT/DALL-E 生成的商業顧問簡報圖：圖示要有細膩的線條粗細與柔和陰影（不是死板的極簡線框），兩欄要有明顯留白與呼吸感，整體精緻、有質感、不擁擠。

**文字量原則：每欄條列最多 3 條、句子越短越好，寧可少寫也不要塞滿——字級要能放大到清楚易讀。**

## 配色與風格
- 主色：深藏青 #1B2A4A；左欄強調色：灰 #6B7280／警示紅 #D9534F；右欄強調色：綠 #2E9E6B
- 背景：純白 #FFFFFF；左右色塊底色要明顯有溫度差異（冷 vs 暖／淡紅 vs 淡綠），但飽和度都要低，避免刺眼
- 字體：無襯線粗體中文標題，一般字重內文，字級寧大勿小
- 圖示風格：像付費 icon 套件等級的圓角線條圖示，帶柔和陰影厚度；左欄圖示可用「叉號/警示」語彙，右欄圖示用「打勾/上升箭頭」語彙，強化對比感
