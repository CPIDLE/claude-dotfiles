# 版型：儀表板型（Dashboard）——「月度 AI 使用量儀表板」

適用主題：定期彙報、數據總結、KPI 追蹤。核心特徵是「頂部大數字統計卡＋下方細節區塊」，強調「一眼看到關鍵數字」而非流程或分類。

套用到新專案時，複製這份的**結構**（標題區／頂部 KPI 卡列／下方細節區塊／底部備註列），內容全部換成自己的主題。KPI 數字必須是全圖視覺重量最大的元素。

---

生成一張寬版(16:9)扁平化商業資訊圖表，純白背景 #FFFFFF，繁體中文，風格盡量貼近 ChatGPT/DALL-E 生成的商業顧問簡報圖：圖示要有細膩的線條粗細與柔和陰影（不是死板的極簡線框），卡片要有明顯留白與呼吸感，整體精緻、有質感、不擁擠。

**文字量原則：KPI 卡只放數字＋一行標籤，細節區塊每項最多 2 條說明，寧可少寫也不要塞滿——數字字級要夠大，是全圖視覺焦點。**

## 配色與風格
- 主色：深藏青 #1B2A4A；KPI 強調色：藍 #2F6FDB／綠 #2E9E6B／橘 #E8873A／紫 #7B5EC7
- 背景：純白 #FFFFFF；卡片底：白或極淺灰 #F8FAFC，帶柔和 drop shadow
- 字體：無襯線粗體中文標題；KPI 數字用最粗最大字重，其餘一般字重，字級寧大勿小
- 圖示風格：像付費 icon 套件等級的圓角線條圖示，帶柔和陰影厚度；示意折線圖只需傳達「上升趨勢」的視覺印象，不需精確數值刻度
