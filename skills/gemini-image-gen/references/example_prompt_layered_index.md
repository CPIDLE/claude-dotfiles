# 版型：分層架構＋索引目錄型（Layered Architecture + Index）

適用主題：系統／產品有明確的分層架構（例如雲端－中樞－終端三層，或總部－區域－門店），同時需要附上一份「目錄式索引」，列出多份子文件、子模組或子圖表各自的位置與摘要。核心特徵是「左側分層架構圖（堆疊層＋雙向箭頭）＋右側編號索引網格」，適合系統架構總覽頁、系列圖集的第一頁導覽、多層產品的技術總覽。

套用到新專案時，複製這份的結構（標題區／右上重點列／左側分層圖／右側索引網格／底部核心價值列／底部應用場景列），內容全部換成自己的主題。索引項目數量建議 6-12 個，排成 2 欄（項目較多時可用 3 欄）網格；分層數量建議 3 層最穩定，太多層畫面會太窄。

---

生成一張寬版(16:9)扁平化商業資訊圖表，純白背景 #FFFFFF，繁體中文，風格盡量貼近 ChatGPT/DALL-E 生成的商業顧問簡報圖：圖示要有細膩的線條粗細與柔和陰影（不是死板的極簡線框），整體精緻、有質感、不擁擠，但這張圖資訊密度較高（含索引網格），排版要工整、對齊，不能鬆散。

**文字量原則：每個索引方塊只放一個粗體小標＋一行極短描述（不超過 12 字），寧可少寫也不要塞滿。**

## 標題區（頂部深藏青滿版橫幅，白字，不是白底黑字——這張圖的標題區用深色底凸顯，跟其他版型不同）
- 主標題（白色，粗體大字，置左）：跨境電商物流平台架構圖集
- 副標題（淺灰白，置左）：由大到細，共 12 圖
- 標題右側放一張產品／系統實拍或渲染小圖（例如物流分撥中心設備、或核心硬體的寫實風插畫），圖右側再放品牌或系統 logo（小字＋簡單圖形標誌即可）
- 最右側 3 個打勾重點列（白底或淺色小圖示＋白字，每項一行極短標題＋極短補充，例如：雲端調度中心／AI 預測配貨；分層安全存取／L0-L2 三層防護；即時可視追蹤／全鏈路狀態回報）

2. 雲端服務層 — 訂單媲合與資料治理

4. 終端裝置層 — 手持掃描與現場執行

## 配色與風格
- **標題區是唯一的深色滿版例外**：頂部標題橫幅用深藏青 #1B2A4A 或更深的藏青漸層滿版鋪底、白字；標題區以下（架構圖／索引網格／底部列）維持其他版型一致的白底風格，不要整張圖都用深色底
- 主色：深藏青 #1B2A4A；三層架構強調色可依序用藍 #2F6FDB／綠 #2E9E6B／紫 #7B5EC7 區分層級；索引網格編號圓用灰藍 #64748B 保持整齊統一（不要每個編號換一色，避免網格看起來雜亂）
- 背景：標題區以下為純白 #FFFFFF；卡片底：白或極淺灰 #F8FAFC，帶柔和 drop shadow；索引網格每格用細灰框線 #E2E8F0 或極淺陰影區隔，維持整齊的表格感；頁尾深色細條可與標題區同色系呼應，首尾包邊
- 字體：無襯線粗體中文標題，一般字重內文，字級寧大勿小；索引網格因項目多，字級可比左側架構圖略小，但仍要清晰可讀；每層內部的技術子層標籤字級再小一級，維持「主層/子層」的視覺層次
- 圖示風格：像付費 icon 套件（Flaticon/Streamline 等級）的圓角線條圖示，帶一點細膩漸層或陰影厚度，不要扁平死板的純線框；標題區的產品／系統實拍或渲染圖要有寫實質感（柔和光影），跟其他純線條圖示區隔出「主視覺」的存在感
