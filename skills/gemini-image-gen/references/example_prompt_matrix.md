# 版型：矩陣／象限型（Matrix）——「風險 x 影響力 優先級矩陣」

適用主題：用兩個維度交叉分類的內容（優先級排序、風險分級、能力盤點）。核心特徵是「X/Y 雙軸座標＋四象限內容」，讀者靠「落在哪一格」理解定位。

套用到新專案時，複製這份的**結構**（標題區／雙軸座標／四象限標籤與內容／圖例），內容全部換成自己的主題。X/Y 軸的兩端意義要清楚標示，不能只寫軸名不寫兩端。

## 標題區
- 主標題（深藏青 #1B2A4A，粗體大字，置中）：風險 × 影響力 優先級矩陣
- 副標題（灰色，置中）：先處理右上角，再依序往外擴散

## 雙軸座標（畫面中央的十字座標系，兩條深灰色主軸線相交於中心，帶箭頭指向外側）
- X 軸（水平，下方標示）：左端「影響力低」，右端「影響力高」
- Y 軸（垂直，左側標示）：下端「風險低」，上端「風險高」

## 四象限（座標系分出的四個區塊，各自淡色底＋圓角，象限內放 2-3 個小圓角標籤卡片，卡片顏色對應象限）

**右上象限（紅／橘底，「高風險高影響」）** 標題：立即處理
標籤：核心模型越權 ／ 資料外洩風險

**左上象限（黃底，「高風險低影響」）** 標題：持續監控
標籤：邊緣情境誤判

**右下象限（藍底，「低風險高影響」）** 標題：規劃優化
標籤：使用者體驗延遲

## 配色與風格
- 主色：深藏青 #1B2A4A（軸線與標題）；象限底色：紅橘 #E8873A（淡化）／黃 #E8C547（淡化）／藍 #2F6FDB（淡化）／灰 #E5E7EB
- 背景：純白 #FFFFFF；象限底色需大幅降低飽和度（接近粉彩），避免與標籤卡片顏色搶視覺
- 字體：無襯線粗體中文標題，一般字重內文，字級寧大勿小
- 圖示風格：像付費 icon 套件等級的圓角線條圖示，帶柔和陰影厚度；座標軸線條要俐落清晰，象限邊界可用極淺的分隔線或純靠底色區分
