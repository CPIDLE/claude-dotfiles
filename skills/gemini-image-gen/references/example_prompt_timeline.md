# 版型：時間軸型（Timeline）——「AI 治理制度導入時程」

適用主題：分階段推進、里程碑、專案時程、演進歷史。核心特徵是「一條主軸線＋依序排列的節點」，讀者的視線被引導沿一個方向（左→右或上→下）移動。

套用到新專案時，複製這份的**結構**（標題區／主軸線／節點卡片／底部列），內容全部換成自己的主題。配色與風格規則可直接沿用，只換強調色數值。

## 配色與風格
- 主色：深藏青 #1B2A4A；強調色依節點順序：藍 #2F6FDB／綠 #2E9E6B／橘 #E8873A（最後一個節點可用主色本身強調「完成」）
- 背景：純白 #FFFFFF；卡片底：白或極淺灰 #F8FAFC，帶柔和 drop shadow
- 字體：無襯線粗體中文標題，一般字重內文，字級寧大勿小
- 圖示風格：像付費 icon 套件等級的圓角線條圖示，帶柔和陰影厚度；主軸線本身要有粗細層次感（不是純細線），節點要像實心珠子有立體感
